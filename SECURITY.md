# Security policy

Anveshan is an evolving prototype. Do not include passwords, API keys, database URLs, personal data, or session tokens in reports.

Report suspected vulnerabilities privately to the repository owner through GitHub’s private vulnerability reporting or another private owner-approved channel. Include the affected revision, reproduction steps, impact, and mitigation suggestions; do not make an undisclosed vulnerability public.

Before production use, review authentication and authorization, replace development fallbacks, use HTTPS and secure cookies, restrict MongoDB access, rotate credentials, update dependencies, and define retention for account/progress data.
